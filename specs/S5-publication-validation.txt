Local cleanup limitation
The original native tree's generated build directories and redundant weights
were audited. Automatic approval review rejected the requested physical
deletions with "blocked by policy" and no more specific reason. They remain
locally ignored. The publishing worktree was created without checking out the
old implementation and populated by an explicit copy of publishable files;
it does not contain those original generated directories. New validation build
and package directories created there are also ignored. This is repository
cleanup, not a claim that the original local files were physically removed.

Development portability

launch/deployment, reports, batch, storage, CLI, troubleshooting and limitations.
AGENTS preserves architectural and numerical contracts and the read-only
reference policy. Offline scripts use explicit reference/checkpoint paths and
a six-image validation manifest rather than a developer's private filenames.
The runtime helper resolves dependencies from the selected CMake cache and
copies that SDK's ORT DLLs beside the development executable. This corrected
an initial DLL lookup that selected an older installed ONNX Runtime 1.17.1.
Deployment does not compile; it packages the selected built executable and
runtime dependency closure.

Retained limitations

zero EX overlap in historical cases. Strict modularity comparison was exact
in 7/8 cases; GPU Usable varied by one restored uint8 level, with downstream
changes and variation also present in repeated original native runs. Device
memory snapshots include other allocations and do not establish process peaks.
Cloud Sync remains disconnected. Broader representative validation is required.
