Native save slots directly called ScreeningReport::writePdf and wrote only one
PDF into the destination. History Download had another PDF-only filename. Save
Both dispatched two independent single saves. There was no shared bundle root,
portable results.json, canonical artifact copying or persisted exported PDF path.
This implements the pc-gpu bundle in the export layer. No IQA, NAFNet, grading,
lesion, model JSON, precision, thresholds, postprocessing, routing or Grad-CAM
code was changed for this report request.

4. ROOT NAME / PATH SAFETY
Existing user-selected destination is required and canonically resolved by
QFileInfo/QDir. Missing destinations fail; arbitrary parent directories are not
created. Root: RetinaGram_<SanitizedPatientName>_<YYYYMMDD_HHMMSS> in local time.
Sanitization removes Windows < > : " / backslash | ? *, controls and whitespace;
trims dots/spaces, caps 64 UTF-16 units without a trailing half surrogate and
falls back to Patient. Values cannot introduce path traversal. Exclusive mkdir
allocates the root, with _2, _3, etc. for collisions including concurrent exports.
Existing roots/files are preserved and never removed by export cleanup.

5. EYE DIRECTORY
OS -> Left_OS; OD -> Right_OD. Other values fail. Each eye has a new subfolder,
PDF and JSON. Save Both appears only with both COMPLETE retained analyses and
allocates one root. Generic helpers accept one completed eye but validate every
requested eye; duplicate eyes and mixed patient IDs/names fail before writing.

6. EXACT DELIBERATE FILES
Per eye:
 report.pdf
 results.json
 original_fundus.jpg
 restored_fundus.png when actual restoration source is present
 lesion_overlay.png when combined overlay is present
 masks/microaneurysm.png when MA source is present
 masks/hemorrhage.png when HE source is present
 masks/hard_exudate.png when EX source is present
 masks/soft_exudate.png when SE source is present
Masks directory exists when a mask is present. Current completed native analyses
have all four, including valid all-zero masks. No recursive run-directory copy,
probability map, CAM, selected-region image, UI screenshot or intermediate file.
Manifest is sorted and relative to the root, including eye directory prefix.

7. ORIGINAL / RESTORATION / OVERLAY
Original image_path is decoded through ImageDecoder, converted RGB888 and saved
by QImageWriter as an actual JPEG at quality 95 with optimized write. PNG/TIFF
files are never just renamed. No overlay or CAM is baked into this original.
restored_image_path is copied unchanged to restored_fundus.png, preserving the
actual image used downstream. Good has no restored file or reference. An analysis
marked restored without that required source fails. Nonempty declared artifact
paths must exist/decode; empty optional paths are omitted. Combined lesion overlay
is copied byte for byte, not regenerated during export.

8. FULL MASK MAPPING
MA -> masks/microaneurysm.png; HE -> masks/hemorrhage.png;
EX -> masks/hard_exudate.png; SE -> masks/soft_exudate.png.
Sources are lesion_mask_paths, the full pipeline masks before display filtering,
merging, Top-K or selection. Copies are byte-for-byte identical. Detection uses
the existing ScreeningReport::Data full-mask/structured-data logic. Region_count
is the saved native count. No new threshold or inference is applied and zero
display count does not falsely imply an empty full mask.

9. results.json SCHEMA
QJsonDocument/QSaveFile write indented UTF-8 JSON:
 report_id: retained run_id, native UUID or stable legacy local identifier
 patient: available name,id,age,gender,eye,scan_datetime,referring_doctor
 image_quality: class,confidence,probabilities
 dr_grading: grade,label,confidence,probabilities
 lesions: MA/HE/EX/SE -> label,detected,region_count,mask_file
 inference_device: retained device_name/device
 pipeline_state: retained COMPLETE
 analysis_source: retained original/restored where available
 original_image_file: original_fundus.jpg
 restored_image_file: restored_fundus.png or null
 generated_at: ISO date/time with milliseconds and local UTC offset
Grade labels 0..4: No diabetic retinopathy, Mild NPDR, Moderate NPDR, Severe NPDR,
Proliferative DR. Lesion labels: Microaneurysms, Hemorrhages, Hard Exudates,
Soft Exudates. Confidence/probability values are copied without renormalizing.
Portable relative mask references have forward slashes. Optional file references
are null when absent; temporary absolute run paths are not serialized. Legacy
snapshots without evidence of full-mask presence/absence use detected=null, matching
the PDF's Unavailable status rather than inventing false absence. Non-finite
floating structured values fail before any report root is created.

10. SINGLE SAVE / PDF
ReportPage uses the existing folder picker; AnalysisController::saveReport calls
exportReportBundle with MainWindow::reportData. History Save Eye/Download uses
the same helper on the retained snapshot. After artifacts and JSON are written,
a copy of report data is adapted to the bundle's image/mask paths and passed to
the unchanged A4 writePdf renderer. PDF and JSON share metadata/analysis results.
Success notice identifies the report ROOT, not merely its PDF.

11. BILATERAL SAVE
ReportPage emits one bothReportsRequested(sessionId,destination) signal. Controller
reads both saved contexts and calls exportReportBundles once. Requested eyes must
be COMPLETE and share patient identity. One root contains Left_OS/Right_OD with
independent conditional restoration. Both JSON/PDFs use one generation instant.
A fatal write in either eye removes the newly allocated shared root, preventing
partial success from being reported.

12. HISTORY / SESSION INTEGRATION
After successful GUI export, rememberReportPath records exported report.pdf in the
appropriate eye's result.report_path. Existing History is matched by its established
session ID; normal current-patient export matches patient ID and retained run ID.
Current patient/active History preview maps update when they reference that run.
Scan timestamps and History session IDs are unchanged; no duplicate session is
created. The shared session-ID helper preserves the existing patient-ID/savedAt/
image-path SHA256 algorithm. saveState returns checked QSaveFile write/commit status.
If bundle success is followed by failed History persistence, UI identifies that
failure and gives the saved root. Damaged session storage remains protected by
the existing stateLoadError guard.
History View Reports keeps its saved-analysis preview behavior. Download exports
a bundle, updates the saved PDF path and does not depend on running inference.
Tests locate/read the actual exported PDF through session.json's saved path.

13. FAILURE HANDLING / ATOMICITY
Preflight completion, eye, original decoding, grade, requested artifact existence/
decoding, patient identity and finite JSON before root allocation. Check every
mkdir, JPEG write, copy, JSON write/commit and PDF result. Descriptive examples:
Selected report destination does not exist; Original retinal image is unavailable;
Cannot copy lesion overlay; Cannot write results.json; Cannot save report.pdf.
Fatal failure releases file handles and removes ONLY the new allocated root. If
cleanup fails, the error includes the incomplete root path. Existing exports and
inference sources are never removed. This is operation rollback, not recovery
from forced process termination/crash or filesystem transactions. No partial
bundle write is returned as a successful export.
